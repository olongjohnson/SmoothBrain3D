# SmoothBrain3D

**3D modeling software for people too stupid for Blender.**

## The Problem

Blender is incredible software built by geniuses for geniuses. The rest of us open it, stare at the default cube, accidentally split the viewport into 47 panels, and close the tab. We just want to make a guy. A little low-poly guy. Maybe give him a sword. Why does that require a PhD?

## The Vision

A mobile-first 3D modeling tool that trades power for approachability. No node graphs. No modifier stacks. No UV unwrapping nightmares. Just touch, drag, sculpt, done.

Target users: game devs who want quick low-poly assets, hobbyists who gave up on Blender, anyone building on a couch with a tablet.

## Core Principles

- **Mobile-first**: Designed for touch from day one, not a desktop app crammed onto a phone
- **Opinionated defaults**: Fewer options, better defaults. Don't ask the user to configure what we can decide for them
- **Low-poly focus**: We're not competing with ZBrush. We're making tools for chunky, stylized geometry
- **Immediate feedback**: Every action is visible instantly. No baking, no waiting, no "apply modifier"
- **Progressive complexity**: Start dead simple, unlock advanced tools as users need them

## Target Output

- Low-poly meshes (think: RuneScape, Minecraft modding, indie game assets)
- Export to glTF/GLB for use in Three.js, Godot, Unity, etc.
- Vertex-colored models (paint directly on geometry)
- Simple rigging for basic character animation

## What This Is NOT

- A Blender replacement for professionals
- A sculpting tool for high-poly organic models
- A full animation suite
- A rendering engine
